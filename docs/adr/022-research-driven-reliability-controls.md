# ADR022: Research-driven reliability controls

Accepted2026-10-19 within the user's explicit reliability research/implementation request. [Research review](../00-research/chatbot-reliability-2026-10-19.md) maps known failures to the existing architecture and outstanding work. Implement observable safeguards and evaluation infrastructure; do not claim a universal SOTA stack or semantic guarantee.

Grounded prompt v2 explicitly distinguishes evidence relevance from sufficiency, memory from evidence, publication date from effective authority, and conflicting sources from a single supported answer. It directs abstention/clarification for missing or ambiguous evidence. It adds no tools or source authority. Prompt/version/request hashes change; old manifests continue to obey existing fingerprint mismatch/recovery rules. Existing v1 files remain for release history. This is a policy/contract hardening change; live-model quality promotion remains unmeasured.

Output integrity v1 runs inside the existing complete-output validator before any draft and again on finalize/replay. Double quotation marks are reserved for verbatim source excerpts. Straight/curly/guillemet quoted spans must occur within one of that sentence's cited passage bodies after NFC and whitespace normalization only. Never concatenate passages, strip negation, case-fold or alter numbers. Reject malformed/empty quotes, inline bracketed E-labels, blank limitations and C0/DEL/C1 or explicit bidi-direction controls (tabs/newlines allowed). Natural RTL text, ordinary apostrophes and script Unicode remain valid. Limitations cannot contain source quotations or citation labels. Display titles still come from authorized passages.

These checks do not prove that a quoted source is true, that a paraphrase follows from it, or that every non-quoted factual claim has support. Unsupported plain prose can still pass. Prompt-injection resistance is provided by layered authority/capability boundaries, not by quotation checks. No automatic LLM repair or unbudgeted verifier call is added. Invalid output uses the existing invalid_model_output failure and cannot be saved as a brief.

Optional query rewriting now preserves signed numeric literals, percentages, identifiers/codes and quoted phrases, and rejects introduced/dropped English negation including contractions. A rejection uses the original question; it does not expand source scope or repeat generation. Conservative false rejections are acceptable for this optional experiment. This is not semantic equivalence checking, multilingual polarity detection or serving promotion.

Selective-answer evaluation remains offline and tied to existing generation plans/observations/human judgments. Scores are ordering signals, not calibrated probabilities. Unknown judgments cannot be counted as correct, failed/missing attempts cannot disappear, and no threshold is automatically selected or promoted on held-out results. Keep quality evaluation distinct from structural/security fixture results.

Source snapshots include packaged `.txt` prompts. Previously the suffix allowlist omitted them, allowing a prompt-only edit to escape source identity. New snapshots deliberately invalidate the earlier incomplete identity; historical results are not relabeled as results for prompt v2. A mutation regression verifies this boundary.

Generation task success now requires every supplied citation link to be supported, in addition to full claim support, citation recall, relevance/completeness and authorization. Previously an extra unsupported link could reduce citation precision without failing task success. The report identifies the corrected rubric as `fully-supported-citations-v2`; do not directly compare old and new task-success scores without rescoring under a common rubric.

The offline context diagnostic exercises the actual packer with designed position/distractor/conflict/missing-evidence/history variations for three fictional organization topics. It does not call retrieval, infer permission scopes, run a generator or supply reviewed labels. Candidate methods remain gated on reviewed semantic/cost evidence; no arbitrary confidence threshold or learned judge is promoted.
