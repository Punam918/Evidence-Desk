# KEYS-01: Credential rotation procedure / revision 1

Signing credentials rotate every 7 days.
The old verification key remains accepted for a 3-minute overlap.
Rotation audit metadata is retained for 30 days.
The private signing key is mounted from a secret file and never placed in browser configuration.
After confirmed compromise, revoke the old key immediately and skip the normal overlap.
Audit events contain the key identifier and action, but never private key bytes.
