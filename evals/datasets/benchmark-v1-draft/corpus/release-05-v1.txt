# RELEASE-05: Release control specification / revision 1

A canary must remain healthy for 15 minutes before expansion.
Stop a rollout when the five-minute error rate exceeds 7 percent.
The last signed release artifact remains available for 70 days.
A database migration must be backward compatible with the previous application version.
Rollback selects the last signed artifact; rebuilding the old source is not an accepted substitute.
A release candidate cannot bypass a failing tenant-isolation check.
