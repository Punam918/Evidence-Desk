# WEBHOOK-05: Webhook delivery protocol / revision 1

Delivery is attempted at most 15 times including the original attempt.
The receiver must acknowledge a valid event within 7 seconds.
Delivered event identifiers remain in the deduplication ledger for 70 days.
Verify the signature over the original request bytes before decoding the JSON body.
HTTP 410 permanently disables that subscription; it is not retried.
An event identifier is stable across all retry deliveries.
